# 📘 User Manual

Panduan lengkap penggunaan aplikasi FinLapor untuk pengguna.

---

## 🎯 Apa itu FinLapor?

FinLapor adalah aplikasi manajemen keuangan yang membantu Anda:
- 📝 Mencatat pemasukan dan pengeluaran
- 📷 Scan struk belanja otomatis
- 📊 Melihat laporan keuangan
- 🤖 Mendapatkan saran dari AI

---

## 🚀 Memulai

### Langkah 1: Daftar Akun

1. Buka website [finlapor.airi.click](https://finlapor.airi.click)
2. Klik tombol **"Daftar"**
3. Isi form pendaftaran:
   - Email
   - Password (minimal 8 karakter)
   - Nama lengkap
   - Pilih mode: **Personal** atau **Business**
4. Klik **"Daftar"**
5. Anda akan diarahkan ke Dashboard

### Langkah 2: Login

1. Buka [finlapor.airi.click](https://finlapor.airi.click)
2. Masukkan email dan password
3. Klik **"Masuk"**

## 💰 Mengelola Transaksi

### Menambah Transaksi Manual

1. Klik menu **Transaksi**
2. Klik tombol **"+ Tambah Transaksi"**
3. Isi form:
   - **Tipe**: Pemasukan atau Pengeluaran
   - **Kategori**: Pilih kategori yang sesuai
   - **Jumlah**: Masukkan nominal (contoh: 50000)
   - **Deskripsi**: Keterangan transaksi
   - **Tanggal**: Pilih tanggal transaksi
4. (Opsional) Upload bukti transaksi
5. Klik **"Simpan"**

### Kategori Transaksi

| Kategori | Contoh |
|----------|--------|
| 🍔 Makan & Minum | Warung, restoran, kopi |
| 🚗 Transportasi | Grab, bensin, parkir |
| 🛒 Belanja | Supermarket, online shop |
| 💡 Tagihan | Listrik, air, internet |
| 🎮 Hiburan | Nonton, game, langganan |
| 🏥 Kesehatan | Obat, dokter, gym |
| 💼 Gaji | Gaji bulanan |
| 💰 Bisnis | Pendapatan usaha |

### Mengedit Transaksi

1. Klik transaksi yang ingin diedit
2. Klik ikon **✏️ Edit**
3. Ubah data yang diperlukan
4. Klik **"Simpan"**

### Menghapus Transaksi

1. Klik transaksi yang ingin dihapus
2. Klik ikon **🗑️ Hapus**
3. Konfirmasi penghapusan

### Filter & Pencarian

- **Filter Tanggal**: Pilih rentang tanggal
- **Filter Kategori**: Pilih kategori tertentu
- **Filter Tipe**: Pemasukan atau Pengeluaran
- **Pencarian**: Ketik kata kunci di kotak search

## 📷 Scan Struk (OCR)

Fitur andalan FinLapor! Cukup foto struk, data akan terinput otomatis.

### Cara Menggunakan

1. Klik menu **Scan Struk**
2. Pilih cara upload:
   - **📷 Kamera** - Foto langsung dari HP/webcam
   - **📁 Upload File** - Pilih file gambar
3. Tunggu proses scanning (2-5 detik)
4. Review hasil:
   - Nama toko
   - Tanggal
   - Total belanja
   - Daftar item (jika terdeteksi)
5. Edit jika ada yang salah
6. Pilih kategori
7. Klik **"Simpan Transaksi"**

### Tips untuk Hasil Terbaik

✅ **DO:**
- Foto dengan pencahayaan cukup
- Pastikan struk datar, tidak kusut
- Foto dari atas, tegak lurus
- Pastikan semua tulisan terbaca

❌ **DON'T:**
- Foto blur atau goyang
- Struk terlipat atau robek
- Cahaya terlalu gelap/terang
- Foto miring

### Format yang Didukung

- JPG / JPEG
- PNG
- PDF (1 halaman)

## 📊 Laporan Keuangan

### Jenis Laporan

| Laporan | Untuk Siapa | Deskripsi |
|---------|-------------|-----------|
| **Ringkasan Bulanan** | Semua | Overview keuangan bulanan |
| **Laporan Laba Rugi** | Business | Income Statement standar akuntansi |
| **Neraca** | Business | Balance Sheet |
| **Arus Kas** | Business | Cash Flow Statement |

### Cara Generate Laporan

1. Klik menu **Laporan**
2. Pilih **Jenis Laporan**
3. Pilih **Periode** (bulan/kuartal/tahun)
4. Klik **"Generate"**
5. Preview laporan di layar
6. Klik **"Download PDF"** atau **"Download Excel"**

## 💬 Asisten AI

Chat dengan AI untuk mendapatkan insight keuangan.

### Contoh Pertanyaan

- "Berapa total pengeluaran saya bulan ini?"
- "Kategori apa yang paling boros?"

### Cara Menggunakan

1. Klik menu **Asisten AI**
2. Ketik pertanyaan di kotak chat
3. Tekan Enter atau klik **Kirim**
4. AI akan menjawab berdasarkan data keuangan Anda

## 💡 Tips & Trik

### 1. Input Transaksi Rutin

Untuk transaksi yang sama setiap bulan (gaji, tagihan), gunakan fitur **"Salin dari Sebelumnya"**.

### 2. Gunakan OCR untuk Belanja

Lebih cepat dan akurat! Cukup foto struk, tidak perlu input manual.

### 3. Review Mingguan

Cek Dashboard setiap minggu untuk memonitor pengeluaran.

### 4. Set Budget

Di mode Personal, set budget per kategori untuk mengontrol pengeluaran.

### 5. Tanya AI

Bingung soal keuangan? Tanya saja ke Asisten AI!
